# Dota 2 Account Checker
Desktop-приложение на JavaFX для глубокого анализа статистики игроков Dota 2. Приложение использует OpenDota REST API для получения данных.

## Фичи
* Вычисление актуального винрейта за последние 20 матчей.
* Расчет максимального перерыва между играми (помогает выявить купленные/вернувшиеся аккаунты).
* Асинхронное выполнение сетевых запросов (UI не блокируется).
* Парсинг ссылок с Dotabuff, Steam или прямого ID.

## Стек технологий
* **Java 17+**
* **JavaFX** (UI)
* **Gson** (JSON Parsing)
* **java.net.http.HttpClient** (Сетевые запросы)

## Как запустить
1. Склонируйте репозиторий: `git clone https://github.com/zxc1477/dota-account-checker.git`
2. Соберите и запустите через Maven: `mvn clean javafx:run`
